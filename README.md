# WIT-HR-Data-Analysis-Project
HR Data Analysis Project using SQL and Power BI

HR Data Analysis Project Overview

This project analyses an HR dataset containing information about employees, departments, job roles, monthly income, job satisfaction, overtime, and attrition.
SQL was used to answer specific analytical questions, while Power BI was used for exploratory data analysis (EDA) and data visualisation.

Objectives

Analyse the HR dataset using SQL.
Examine employee income, departments, job roles, job satisfaction, overtime, and attrition.
Use Power BI to explore patterns in the data.
Present findings through clear visualisations.
Draw meaningful conclusions from the analysis.

Tools Used

SQL Server Management Studio (SSMS) – SQL analysis
Microsoft Power BI – Exploratory data analysis and visualisation
Microsoft Excel – Original dataset
GitHub – Project documentation and file storage

SQL Analysis

Seven SQL queries were developed to analyse:
Employees in the Sales department earning more than $5,000 per month.
The number of distinct job roles.
Total employees and average monthly income by department.
Male and female employees working overtime.
Job roles with low average job satisfaction.
Employee attrition and attrition rates by department.
Employees earning above the company-wide average monthly income.

Power BI Analysis

The Power BI dashboard provides an overview of:
Total employees
Average monthly income
Employees by department
Average monthly income by department
Attrition by department
Employees by job role
Average job satisfaction by job role
Employees by overtime and attrition

Key Findings

The dataset contains 1,470 employees.
R&D has the largest workforce with 961 employees, followed by Sales with 446 and HR with 63.
Sales has the highest average monthly income at approximately $6,859.17.
Sales Executive is the largest job role, with 326 employees.
Healthcare Representative has the highest average job satisfaction at 2.79.
Employees who worked overtime showed a higher proportion of attrition than those who did not. This indicates an association between overtime and attrition, but does not establish that overtime causes employees to leave.

Conclusion

The project demonstrates how SQL and Power BI can be used together to transform raw HR data into useful information. SQL provided specific answers to the required analytical questions, while Power BI supported broader exploration and visualisation of workforce patterns.
The analysis highlights differences in workforce distribution, income, job roles, job satisfaction, overtime, and attrition. These findings can help identify areas that may require further investigation within an organisation.
